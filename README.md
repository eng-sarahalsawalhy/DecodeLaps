# DecodeLaps

A collection of beginner Python and Machine Learning projects developed to practice programming, logic building, and supervised learning concepts.

## Projects

### 1. Recommendation System
A simple recommendation system that suggests items based on user preferences.

**Features:**
- Takes user input
- Matches preferences using logic
- Displays recommendations

**Skills Used:**
- Python
- Conditional Statements
- Pattern Matching

---

### 2. Classification Model
A basic machine learning classification model built using the Iris dataset and a Decision Tree Classifier.

**Features:**
- Loads and explores a dataset
- Splits data into training and testing sets
- Trains a classification model
- Evaluates model accuracy

**Skills Used:**
- Python
- Scikit-learn
- Supervised Learning
- Data Handling

---

### 3. ChatBot
A simple rule-based chatbot that interacts with users through predefined responses.

**Features:**
- Greets users
- Answers basic questions
- Handles exit commands
- Runs continuously until the user exits

**Skills Used:**
- Python
- Loops
- Conditional Statements
- User Interaction

---

## Technologies Used

- Python
- Scikit-learn
